## CORE Guarantees Shipped
1. **Tri-State Values:** Three immutable, distinct states: `xox.TRUE`, `xox.FALSE`, and `xox.UNKNOWN`.
2. **Strict Ingress Promotion:** `xox.from_bool()` accepts only exact Python `bool` values (`True`/`False`), rejecting all other types with `TypeError`.
3. **Truthiness Prohibition:** `__bool__` raises `TypeError` for all XoX values, preventing implicit boolean coercion.
4. **Strong Kleene ($K_3$) Logic:**
   - Bitwise inversion `~` implements $K_3$ NOT (`~UNKNOWN == UNKNOWN`).
   - `.lazy_and()` and `.lazy_or()` take zero-argument callables and execute short-circuit evaluation without evaluating unneeded branches.
5. **Explicit Egress Collapse:** `.collapse_or()` requires a zero-argument callable returning exact Python `bool`, evaluated only when state is `xox.UNKNOWN`.
